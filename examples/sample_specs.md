# Sample Specs

Three short specs, one per worker type, used by `python -m hive_lg.demo`.

## Spec 1: Researcher
**Spec:** Explain the difference between LangChain and LangGraph in under 200 words.
**Acceptance criteria:** Output is under 200 words. It names both LangChain and LangGraph. It states a concrete distinction in purpose (composition vs stateful graph orchestration).

## Spec 2: Coder
**Spec:** Write a Python function that returns the nth Fibonacci number iteratively. No recursion.
**Acceptance criteria:** Output contains a Python function definition. The function is iterative (no recursive self-call). The function handles n=0 and n=1 correctly. No external dependencies.

## Spec 3: Writer
**Spec:** Draft a two-paragraph LinkedIn post announcing an open-source LangGraph reference implementation.
**Acceptance criteria:** Output is exactly two paragraphs. It mentions LangGraph by name. The tone is professional and suitable for LinkedIn.
